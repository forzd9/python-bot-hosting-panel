# لوحة إدارة استضافة بوتات Python

> اسم المستودع على GitHub: `python-bot-hosting-panel`. يصف العنوان محتوى المشروع؛ لم يُشغّل التطبيق أو تُختبر قابليته بعد.

## نبذة

يحتوي المستودع على تطبيق ويب مبني باستخدام Flask لإدارة حسابات وخوادم بوتات Python. يوفّر `app.py` صفحات ولوحات للمستخدم والإدارة وواجهات API لإدارة عمليات البوتات وملفاتها وسجلاتها.

المراجعة هنا مبنية على قراءة ساكنة لـ `app.py` و`requirements.txt`. لا يتضمن جذر المستودع README حاليًا، ولم تُشغّل الشيفرة أو الاختبارات ولم تُثبّت الاعتماديات؛ لذلك لا يُعد هذا الوصف تأكيدًا على أن التطبيق يعمل أو جاهز للاستخدام.

## ما يظهر في المصدر

- تسجيل الدخول وإدارة جلسات المستخدم، مع مسارات منفصلة لوظائف الإدارة.
- إنشاء وإدارة حسابات وخوادم البوتات.
- بدء عمليات البوتات وإيقافها وإعادة تشغيلها، وعرض السجلات وبعض الإحصاءات.
- استعراض الملفات ورفعها وتنزيلها وإنشاؤها وتعديلها وحذفها، بما في ذلك رفع ملفات ZIP.
- تثبيت متطلبات البوت من ملف المتطلبات الخاص به عبر واجهة الإدارة.
- تخزين بيانات المستخدمين والإعدادات وسجل أمني في ملفات JSON/سجل، واستخدام مجلدات لملفات البوتات والسجلات.

هذه قائمة بالمسارات والسلوك الظاهرين في المصدر، وليست ضمانًا لاكتمال كل مسار أو صحته أو توفر عزل بين المستخدمين والعمليات.

## المتطلبات المذكورة في المستودع

يحتوي `requirements.txt` على الإصدارات التالية:

- `Flask==2.3.3`
- `psutil==5.9.6`
- `bcrypt==4.1.2`
- `python-telegram-bot==22.8`

المستودع لا يحدد إصدار Python موصى به أو نظام تشغيل مدعومًا. كما أن وجود حزمة في ملف المتطلبات لا يثبت وحده أنها مطلوبة لكل مسار من التطبيق.

## الإعداد والتشغيل (غير مجرّبين)

تستند الخطوات التالية إلى ملف المتطلبات ونقطة بدء التطبيق الظاهرة في `app.py`، ولم تُنفّذ ضمن هذه المراجعة:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

يدعم المصدر قراءة متغير البيئة `PORT` للمنفذ، ويستخدم `SECRET_KEY` لإعداد مفتاح جلسة Flask. لا تضع أسرارًا فعلية في المستودع أو في سجل الأوامر. راجع إعدادات المصدر قبل أي تشغيل، وخصوصًا بيانات اعتماد الإدارة المضمّنة فيه، وغيّرها أو انقلها إلى آلية أسرار مناسبة قبل الاستخدام.

بحسب إعداد الخادم في المصدر، يرتبط التطبيق على جميع واجهات الشبكة (`0.0.0.0`). لا تعرضه مباشرةً على الإنترنت دون مراجعة أمنية وإعداد شبكة مناسب. لم تُتحقق هذه الخطوات عمليًا، ولا توجد في المستودع تعليمات موثقة لنشر آمن.

## البيانات والملفات

يشير المصدر إلى ملفات مثل `users.json` و`config.json` وسجل `security.log`، وإلى مجلدات لبيانات التطبيق والبوتات والملفات المرفوعة. تعامل مع هذه البيانات على أنها حساسة؛ احمِ صلاحيات الملفات والنسخ الاحتياطية، ولا ترفع بيانات مستخدمين أو جلسات أو أسرار إلى Git.

## تنبيهات أمنية وحدود المشروع

- تشغّل اللوحة ملفات Python مرفوعة أو مُدارة، وتستطيع تثبيت اعتماديات يحددها ملف يرفعه المستخدم. يمنح ذلك الشيفرة المنفذة واعتمادياتها قدرة على التأثير في بيئة الخادم.
- لا يثبت المستودع وجود عزل حاويات أو حدود موارد أو عزل أمني موثوق لعمليات البوتات. لا تستضف ملفات غير موثوقة أو مستخدمين غير موثوقين على هذا التطبيق.
- يظهر في المصدر اعتماد إداري ثابت؛ لا تُعد استخدام بياناته، ولا تنشر التطبيق قبل استبدالها والتحقق من آلية إدارة الحسابات والأسرار.

- الربط على `0.0.0.0` يزيد أهمية تقييد الوصول بجدار ناري أو شبكة خاصة ومراجعة إعدادات النشر.
- لا يتضمن المستودع توثيقًا كافيًا للنشر أو سياسة خصوصية أو وصفًا مثبتًا للعزل. لم تظهر مجموعة اختبارات أو نتائج تحقق في الملفات التي تمت مراجعتها.
